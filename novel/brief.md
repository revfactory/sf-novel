# 집필 브리프

상태: 구상 전. 사용자는 SF 소설 집필 의향을 밝혔으며, 작품 설정은 아직 정하지 않았다.

| 항목 | 현재 값 | 상태 |
| --- | --- | --- |
| 작업 언어 | 한국어 | 대화 언어에 따른 작업 가정 |
| 제목·한 줄 전제 | 미정 | 미정 |
| 하위 장르·주요 소재 | 미정 | 미정 |
| 단편/중편/장편·목표 분량 | 미정 | 미정 |
| 독자·주제·분위기 | 미정 | 미정 |
| 과학 엄밀도·허용할 창작 전제 | 미정 | 미정 |
| 주인공·주요 갈등·결말 | 미정 | 미정 |
| 시점·시제·문체 | 미정 | 미정 |
| 포함하거나 피할 요소 | 미정 | 미정 |

## 다음 집필 작업
소재가 있으면 그 소재를 바탕으로 전제·주인공·딜레마를 구체화한다. 없다면 서로 다른 SF 구상안 3개부터 제안한다. 세부 양식을 모두 채우기 전에도 구상을 시작할 수 있다.

## 범위와 완료 기준
현재 요청은 집필을 위한 하네스 구축이다. 다음 집필 요청의 산출물 범위와 분량 기준은 그 요청에서 정한다. 미정 항목을 사용자 확정으로 해석하지 않는다.
