# SF 소설 검토 보고서

- 검토 ID / 대상 파일·버전:
- 참조 정본·브리프·플롯의 버전:
- 배정된 범위 / 실제 검토 범위 / 미검토 범위:
- 원고 판정: pass / revise / blocked
- 핵심 판단과 근거:
- 분량 조건·계산법·실측값(범위에 포함될 때):

## 결함

발견한 결함마다 복사한다. 결함이 없으면 확인한 범위와 근거를 적는다.

### 결함 ID

- 심각도: blocker / major / minor
- 위치: 파일·버전·장면 ID·행 또는 짧은 인용
- 관찰한 문제:
- 충돌하는 요구·정본·다른 장면·자료:
- 독자 경험·후속 장면에 미치는 영향:
- 최소 수정안:
- 수정 시 다시 확인할 범위:
- 판단의 불확실성·메인 결정이 필요한 사항:

## 과학 확인

| 주장·위치 | 사실 / 외삽 / 창작 가정 | 출처 제목·URL·확인 날짜 | 적용 조건·불확실성 | 확인 / 미검증 |
| --- | --- | --- | --- | --- |

## 취향 제안

선택 이유와 효과를 적고 필수 결함과 분리한다.

## 재검토 기록

| 결함 ID | 새 원고 버전 | 해결 / 잔존 / 사용자 명시 의도 / 검증 불가 | 위치와 확인 근거 | 영향 범위 재확인 |
| --- | --- | --- | --- | --- |

## 인계

- 우선 수정할 결함 ID:
- 메인이 판단할 정본·범위 변경:
- 남은 문제·미검증 범위:
- 실제 수행한 확인과 결과:
- 이번 보고서의 작업 상태: completed / blocked / failed
